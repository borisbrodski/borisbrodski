## Web applications

Django came after years of Rails and Java EE, so the architecture habits were already there: clear models, thin views, migrations under control, tests. The current Django/PostgreSQL site is one I operate as well as develop — containers, backups, upgrades.

## Native Python

For a CAD manufacturer I built the bridge that lets Python load and process data through a C++ library, across several Python versions and both 32- and 64-bit architectures, with an automated test matrix. The same C++ and build-system background covers packaging, wheels and the parts of Python that are not Python.

## Data and models

Python is also the language of my machine-learning work — see [AI & machine learning](/ai/): TensorFlow pipelines, OpenCV inference services, a Gtk desktop application, PostgreSQL feature stores for trading models.
