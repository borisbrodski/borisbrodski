## openbrod.org

All my open-source work is collected at **[openbrod.org](https://openbrod.org)** — project pages, documentation, release notes and the roadmap for each. GitHub is at [github.com/borisbrodski](https://github.com/borisbrodski).

## The projects

**7-Zip-JBinding** is the long-runner: a Java binding for the 7-Zip compression algorithms, founded in November 2007 and maintained ever since, with native builds for Windows, Linux and macOS in 32 and 64 bit plus ARM. Around ten thousand downloads a month on Maven Central.

**Torhaus** is the newest: a framework that runs any AI agent harness in kernel-enforced compartments with default-deny egress, a credential broker and a tamper-evident audit log — built on the assumption that the model itself may be hostile. Apache-2.0, early development.

**Redmine plugins** — workflow integration with Git and Gerrit, data-exchange plugins, and the audits of other people's plugins that come with running Redmine in production.

**xtextcasts.org** — screencasts on Xtext and language engineering.

## How I work in the open

Reproducible builds, a test suite on every supported platform, release notes that say what changed, and issues answered. Contributions welcome on all of them.
