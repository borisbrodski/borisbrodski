## Redmine

Redmine is Rails with fifteen years of conventions on top, and plugins are where it gets interesting. Since 2022 I maintain a large plugin suite for an energy-sector client — bidirectional data exchange and data maintenance with external systems — and I run the installation: containerised with Podman, backed up with Restic, load-tested with JMeter, with production data anonymised before it reaches any other environment. Every third-party plugin gets a security audit before it is deployed.

The first Redmine work was in 2010: a plugin that automated feature-driven development — a branch per issue, branch monitoring, Gerrit review requests generated from commits — later reused to streamline the workflow of an insurance project.

## Puppet

Ruby is also the language of Puppet, which describes the infrastructure of the Java platform I architect. Writing modules, testing them, keeping environments reproducible.

## What I do for clients

- Redmine plugins: new development, maintenance of grown plugin landscapes, upgrades across Redmine versions.
- Security audits of Rails applications and plugins.
- Hosting and operations: containers, backups, anonymised staging data.
- Rails applications beyond Redmine, and Puppet infrastructure code.
