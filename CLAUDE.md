# brodski.name — personal site of Boris Brodski

Static site, generated by `build.py` (Python, Jinja2, PyYAML, Markdown) into `_site/`, deployed to
GitHub Pages on push to `main`. Custom domain `brodski.name` (CNAME written by the build).

## The one rule
This repository is **public**. Never add: phone numbers, street address, date of birth, employer
reference letters, certificate scans, client names beyond the sector, or anything from a private CV
that is not already on the site. Email `Boris@Brodski.name` and city `Düsseldorf` are fine.

## How content works
- `data/projects.yaml` — every project exactly once. `directions: {slug: {rank, blurb}}` decides on
  which spoke pages it appears and with which wording. Rank 1 = headline work, 2 = strong support,
  3 = one line. A project with no tag for a direction does not appear there — that is the point:
  a visitor looking for Rails must not see C++ achievements.
- `data/skills.yaml` — grouped skills with `level` 1–5, `start`, `end` (null = ongoing) and
  `directions`. The CV page shows all; spoke pages filter. The timeline SVG is generated from this.
- `data/talks.yaml`, `data/education.yaml`, `data/site.yaml` (directions, nav order, hero cards).
- `pages/<slug>.md` — per-page narrative: front matter `title`, `lead`, `description`, `pitch`
  (3–4 markdown bullets) + markdown body. `pages/index.md` is the hub intro.
- To add a direction: add it to `site.directions`, create `pages/<slug>.md`, tag projects/skills.

## Style
- British/neutral English, concrete over adjectival, numbers where they exist (years, team sizes).
- Positioning: "security from the transistor to the model"; security is the through-line, not a pivot.
- No framework, no build tool beyond `build.py`; keep `style.css` the only stylesheet.
- Keep the generated `_site/` out of git.

## PDFs
Drop `static/cv/boris-brodski-<slug>.pdf` (one-page CV per direction) and `static/cv/*-de.pdf`
(full German Qualifikationsprofil). The build links them automatically when present.

## Verify
`make serve`, open http://localhost:8000, check a spoke page, the CV page, and phone width.
